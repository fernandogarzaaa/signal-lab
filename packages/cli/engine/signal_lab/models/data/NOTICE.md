# Notice: Loughran-McDonald Word Lists

## What this is

`lm_lexicon.json` contains positive, negative, and uncertainty word lists
derived from the Loughran-McDonald Master Dictionary, a finance-specific
sentiment lexicon built from 10-K filings.

- Copyright holders: Tim Loughran and Bill McDonald, University of Notre Dame.
- Source: Software Repository for Accounting and Finance (SRAF),
  https://sraf.nd.edu/loughranmcdonald-master-dictionary/
- Dictionary version: 1993-2025 master release (March 2026).
